1. Executive Summary & System Overview

The R.M.K. AI Campus Concierge – Smart Kiosk & Navigation System is an enterprise-grade digital kiosk application designed specifically for R.M.K. Engineering College (Kavaraipettai, Tamil Nadu). Engineered for touch terminals deployed at key campus locations—such as the Main Gate Plaza, Administration Block, and Central Library—the system acts as a 24/7 intelligent guide for students, parents, faculty, accredited visitors, and guests.

Key Strategic Goals & Capabilities

  • Interactive 2D Site Plan & A* Pathfinding: Vector-based walking route calculation across 21+ campus buildings with turn-by-turn navigation instructions.
  • AI Conversational Assistant ("Ask RMK AI"): Natural language query resolution grounded on institution-specific academic, administrative, and hostel knowledge.
  • Real-time Campus Logistics: Faculty location finder, bus route tracker, hostel meal menus, and campus event schedules.
  • Kiosk-Grade UX/UI: Custom 16:9 display bezel framing, automated 45-second inactivity reset timer, multi-language speech capabilities, and QR mobile handoff.

3. System Architecture & Component Hierarchy

The system follows a modular architecture separating presentation components, contextual state management, and algorithmic processing engines.

Data Flow & Execution Pipeline

  1. User Touch / Speech Event: Triggered via physical kiosk screen interaction or Web Speech voice prompt.
  2. Global State Dispatch: NavigationContext handles destination state, active tab key, and route graph calculations.
  3. Algorithmic Processing:
    • For Wayfinding: navigationGraph.ts executes A* search over NODES and ROADS arrays.
    • For AI Queries: ragEngine.ts processes intent patterns and returns grounded response data + quick action navigation handlers.
  4. DOM Synchronization: React updates view components, redrawing SVG vector path overlays or streaming AI response text.

4. Detailed Module Specifications

4.1 Home Overview Module

Serves as the default kiosk splash and landing interface. Features an authentic RMK photo carousel with dark gradient overlay, 4 primary quick-action cards (Campus Pathfinder, Ask RMK AI, Campus Facilities, Admissions & Guides), a 3-step usage explanation, and a 45-second inactivity reset countdown.

4.2 Campus Pathfinder & Interactive Site Plan

An interactive vector navigation module displaying 21+ official RMK Engineering College buildings:

  • Academic Blocks: Lakshmikanthammal Block (LKB), R.J. Block (Admin & Placement), V.R. Block (EIE/ECA), S.V. Block (Mech/Civil), New Block (CSE/EEE/ADS), R.M. Blocks (Wing 1 ECE & Wing 2 IT).
  • Labs & Facilities: Swaminadha Naidu Block (Central Library & Computer Centre), P.V. Block, S.S. Block, AICTE IDEA Lab.
  • Hostels & Dining: Boys Hostels (I, II, III & IV Year), Girls Hostels (North, Mid, Central, South), Central Mess Blocks.
  • Campus Amenities: Sports Complex & Track, Eco Pond, Generator House, STP, Rain Water Harvesting Pond, Lord Ganesha Temple, and Main Gate Highway Access.

4.3 Ask RMK AI Assistant

Intelligent chatbot grounded in official RMK knowledge. Resolves questions regarding department locations, admission guidelines, library hours, and placement cell info. Responses include clickable "YES, NAVIGATE" and "VIEW ON MAP" buttons that directly set the route in the Pathfinder.

4.4 Logistics & Campus Life Modules

  • Faculty Finder: Filterable database of professors across departments with cabin block codes and live availability indicators.
  • Bus Routes & Transit: Details 60+ college bus routes connecting Chennai, Thiruvallur, and Andhra Pradesh border districts with departure timings.
  • Hostels & Dining: Daily mess menus (Breakfast, Lunch, Snacks, Dinner) and hostel administration contacts.
  • Admissions & Guides: Comprehensive BE/BTech course catalog, document checklists, and TNEA counseling workflow (price/fee details completely excluded per institutional policy).

Production Build
